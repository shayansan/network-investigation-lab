# Network Investigation Lab

A hands-on Blue Team networking lab focused on packet capture, traffic analysis, and basic network investigation.

## Project Goal

The goal of this project is to practice core networking concepts from a Blue Team and SOC Analyst perspective by generating, capturing, and analyzing real network traffic.

The project focuses on understanding how normal and suspicious network activity appears in packet captures and how an analyst can reconstruct network connections using tools such as Wireshark and tcpdump.

## Lab Scope

This project covers:

- IPv4 addressing
- MAC addressing
- ARP
- ICMP
- TCP and UDP
- TCP three-way handshake
- TCP flags
- Ports and sockets
- DNS
- HTTP
- HTTPS and TLS
- SSH
- Routing basics
- Default gateway
- Basic port scanning behavior
- Repeated and periodic connections
- PCAP investigation
